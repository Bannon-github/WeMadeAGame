The Harness

Agents that move fast. Guardrails that don't move.

Our harness runs in production on our own products. Each stage can read the one before it, but holds strictly fewer permissions than the next — a poisoned web page can, at worst, produce a bad paragraph. Never code.

Least privilege

No agent holds web access and write access at the same time.

Drafts, never pushes

Everything an agent produces arrives as a draft pull request.

Self-reflecting

A weekly reflection flags stalled loops, untested code and bottlenecks.

Model-agnostic

Any OpenAI-compatible provider. Swap models without touching code.
